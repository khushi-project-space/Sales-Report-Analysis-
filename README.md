## 📊 Project Overview

This dashboard transforms raw retail sales data into actionable business intelligence. It provides deep visibility into sales trends, order volumes, revenue breakdowns, and key commercial performance metrics.

### Key Performance Indicators (KPIs)
* **Total Revenue:** Track overall business earnings and sales generation.
* **Total Orders:** Monitor transaction volume and customer activity.
* **Total Quantity Sold:** Analyze product movement and inventory demand.
* **Average Order Value (AOV):** Measure the average spend per transaction.

---

## 🔍 Key Insights & Visualizations

1. **Sales & Revenue Trends:** Identifies top-performing sales channels, categories, and peak periods.
2. **Order Distribution:** Analyzes purchasing patterns and transaction counts.
3. **Product Performance:** Evaluates demand across various retail items.
4. **Customer & Regional Metrics:** Highlights key demographic or regional contributions to overall revenue.

## 🗂️ Files Included in this Repository

* `Project1.pbix` (or core Power BI report file) — The core Power BI desktop report containing all data models, DAX measures, and interactive visuals.
* `Retail_Sales_Dashboard_Dataset_200_Entries.xlsx` — The primary backend dataset containing transaction records, entries, and performance data.

## 🚀 How to Use

1. **Prerequisites:** Ensure you have [Microsoft Power BI Desktop](https://powerbi.microsoft.com/) installed on your system.
2. **Clone/Download:** Download the repository files to your local machine.
3. **Open Report:** Double-click the `.pbix` file to launch the dashboard in Power BI.
4. **Interact:** Use the built-in slicers and filters to dynamically explore trends across different categories, dates, and regions.
